# 향후 기능 백로그

현재 제품 범위에서 미룬 기능만 기록한다. 구현을 마친 항목의 이력은 Git에서 확인한다.

## 기능 후보

### 기록

- 이전·다음 기록 이동
- 기록 공유 링크
- 반응
- soft delete, 휴지통, 삭제 복구
- 기록 변경 이력
- 여러 기록 일괄 수정·삭제
- 목록 inline edit
- 사진 첨부·미리보기와 Supabase Storage 저장

### 장소와 검색

- 현재 위치 기반 주변 장소 검색
- 검색 자동완성 또는 입력 중 검색
- 직접 장소 입력
- 장소 이름 수정
- 장소 지도 미리보기
- 지도에서 장소 선택
- 여러 장소 provider 지원
- 저장 장소 목록 페이지네이션 또는 무한 스크롤

### 지도와 탐색

- 지도 cell 선택과 지역 요약·툴팁
- 기간별 지도 필터
- 실제 Kakao 지도 SDK

### 계정과 운영

- 소셜 로그인
- 비밀번호 재설정
- 인증 이메일 템플릿 커스터마이징
- 관리자 권한

### PWA와 배포

- 오프라인 캐싱
- 자동 설치 안내
- 기록 리마인더 알림
- 앱 스토어 배포(TWA, Capacitor)
- 다크 모드 전용 앱 아이콘

### 데이터와 성능

- 기록 실시간 구독
- SQL aggregation
- 데이터베이스 view 또는 materialized view
- 개발·데모용 seed 데이터

### UI와 접근성

- 입력 경계, 포커스 표시, 일반 텍스트의 색 대비 재검증과 보정
- 홈 지도에 방문 지역 요약·범례와 보조기기용 지역 정보 제공
- 경로별 문서 제목과 본문 바로가기 링크
- 기록 작성 퍼널의 폼 오류 발생 시 첫 오류 필드로 포커스 이동
- 입력 placeholder 규칙 통일
- 마우스 환경의 hover 피드백

## 현재 제품 방향에서 제외

- 지도 확대와 이동
- 한 기록에 여러 지역 연결
- 리 단위 지역 선택
- 숫자로 분할된 행정동 선택

## 기술적 비목표

아래 항목은 사용자 기능이 아니라 복잡도를 필요 시점까지 미루기 위한 구현 원칙이다.

- 과도한 domain abstraction
- 별도 인증 상태 관리 라이브러리
- 별도 전역 상태 관리
- optimistic update
- 여러 장소 provider를 위한 선행 추상화

실제 요구나 측정 가능한 성능 문제가 생길 때만 도입 여부를 다시 검토한다.
