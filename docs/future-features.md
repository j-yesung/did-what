# 향후 기능 백로그

현재 제품 범위에서 미룬 기능을 모은 문서다. 바로 진행할 작업은 `next-app-plan.md`, 현재 제품 기준은 `app-plan.md`에서 관리한다.

## 향후 기능 후보

### 기록

- 기록 목록 페이지네이션 또는 무한 스크롤
- 이전·다음 기록 이동
- 기록 공유 링크
- 댓글과 반응
- soft delete와 휴지통
- 삭제 취소와 복구
- 기록 변경 이력
- 여러 기록 일괄 수정·삭제
- 목록 inline edit
- 사진 첨부
- 이미지 미리보기
- 이미지 업로드
- Supabase Storage 연결

### 사람

- 관계 유형 관리
- 프로필 사진
- 사람별 기록 통계
- 사람 검색
- 사람 정렬 옵션
- 사람 목록 페이지네이션 또는 무한 스크롤

### 장소와 검색

- 현재 위치 기반 주변 장소 검색
- 검색 자동완성
- 입력 중 검색
- 직접 장소 입력
- 장소 이름 수정
- 장소 지도 미리보기
- 지도에서 장소 선택
- 여러 장소 provider 지원
- 저장 장소 목록 페이지네이션 또는 무한 스크롤

### 지도와 탐색

- 지도 cell 클릭과 툴팁
- 지역별 기록 목록
- 기간별 지도 필터
- 사람별 지도 필터
- 실제 Kakao 지도 SDK

### 현재 제품 방향에서 제외

- 지도 확대와 이동
- 한 기록에 여러 지역 연결
- 리 단위 지역 선택
- 숫자로 분할된 행정동 선택

### 계정과 운영

- 소셜 로그인
- 비밀번호 재설정
- 인증 이메일 템플릿 커스터마이징
- 관리자 권한

### PWA와 배포

- 서비스 워커와 오프라인 캐싱
- 자동 설치 안내
- 푸시 알림
- 앱 스토어 배포(TWA, Capacitor)
- 다크 모드 전용 앱 아이콘

### 데이터와 성능

- 기록 실시간 구독
- SQL aggregation
- 데이터베이스 view 또는 materialized view
- 개발·데모용 seed 데이터
- 데이터 증가 시 하단 탭 프리패치 범위 재조정

## 기술적 비목표

아래 항목은 사용자 기능이 아니라 복잡도를 필요 시점까지 미루기 위한 구현 원칙이다.

- 과도한 domain abstraction
- 별도 인증 상태 관리 라이브러리
- 별도 전역 상태 관리
- optimistic update
- 여러 장소 provider를 위한 선행 추상화

실제 요구나 측정 가능한 성능 문제가 생길 때만 도입 여부를 다시 검토한다.
