## 기술적 비목표

아래 항목은 사용자 기능이 아니라 복잡도를 필요 시점까지 미루기 위한 구현 원칙이다.

- 과도한 domain abstraction
- 별도 인증 상태 관리 라이브러리
- 별도 전역 상태 관리
- optimistic update
- 여러 장소 provider를 위한 선행 추상화

실제 요구나 측정 가능한 성능 문제가 생길 때만 도입 여부를 다시 검토한다.
