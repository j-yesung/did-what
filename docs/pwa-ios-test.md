# iOS 설치 확인 시나리오

> 대상: 현재 PWA 구현의 매니페스트, 아이콘, 세이프 에어리어

실기기에서만 확인할 수 있는 항목을 모았다. 코드로 검증 가능한 것은 이미 확인했으므로 여기서는 다루지 않는다.

## 0. 준비

```bash
pnpm build && pnpm start -H 0.0.0.0
```

같은 와이파이의 iPhone Safari에서 맥의 LAN 주소로 접속한다. 주소는 `ipconfig getifaddr en0`으로 확인한다.

- 로그인이 되지 않으면 Supabase 쿠키가 HTTPS를 요구하는 경우다. 배포본에서 테스트한다.
- 홈 화면에 이미 추가해 둔 것이 있으면 아이콘 변경 확인을 위해 먼저 삭제한다.

## 1. 설치 전 (Safari)

- [ ] 탭에 파비콘이 보인다. (실패: 지구본 기본 아이콘)
- [ ] 공유 → 홈 화면에 추가 미리보기에 앱 아이콘이 나온다. (실패: 페이지 스크린샷)
- [ ] 미리보기 이름이 `뭐했지`다.

## 2. 홈 화면 아이콘

- [ ] 아이콘 뒤에 검은 배경이 비치지 않는다.
- [ ] 아이콘 아래 이름이 `뭐했지`다.
- [ ] 아이콘의 파랑 계열이 앱의 브랜드 색과 자연스럽게 이어진다.

## 3. 첫 실행

- [ ] 별도 시작 화면 없이 첫 페이지가 바로 표시된다.
- [ ] 주소창과 하단 툴바가 없다. (실패: standalone 미적용)
- [ ] 로그인 화면이 뜬다. 설치 앱은 Safari와 저장소가 분리돼 재로그인이 필요하다. 정상 동작이다.

## 4. 세이프 에어리어

이번 작업의 핵심이다. `viewport-fit=cover`를 켠 뒤라 실기기에서만 확인된다.

상단

- [ ] 화면 제목이 다이나믹 아일랜드·노치에 가리지 않는다.
- [ ] 시계·배터리 표시와 콘텐츠가 겹치지 않는다.
- [ ] 라이트·다크 모드 모두 상태 표시줄 글자가 배경 위에서 읽힌다. (실패 시 `statusBarStyle` 조정)

하단

- [ ] 탭 라벨이 홈 인디케이터 막대와 겹치지 않는다.
- [ ] 탭바 배경이 화면 맨 아래까지 닿는다. (실패: 아래에 흰 띠가 남음)
- [ ] 탭바가 좌우 끝까지 닿는다. (실패: 양옆에 배경색 틈)
- [ ] 곡선 모서리에서 잘리는 것이 배경색뿐이다. (실패: 라벨이 잘림)

스크롤

- [ ] 목록을 끝까지 내렸을 때 마지막 카드가 탭바에 가려지지 않는다.

## 5. 화면별 점검

- [ ] **지도(홈)** 지도가 세로로 꽉 차고, `기록 남기기` 버튼이 탭바에 가리지 않는다.
- [ ] **기록** 검색창을 탭했을 때 키보드가 입력창을 가리지 않는다. `기간` 패널과 날짜 피커가 동작한다.
- [ ] **기록** 사람 칩 다중 선택이 된다.
- [ ] **기록** 지역 검색 다이얼로그가 상태 표시줄 아래로 파고들지 않는다.
- [ ] **기록** 메모 입력 시 키보드와 입력창이 겹치지 않는다.
- [ ] **장소** 카드의 삭제와 기록 보기 버튼이 오탭 없이 눌린다.
- [ ] **설정** 로그아웃 후 로그인 화면의 상하 여백이 적절하다.

## 6. 재실행과 세션

- [ ] 앱을 완전히 종료(앱 스위처에서 위로 밀기)한 뒤 재실행해도 로그인이 유지된다.
- [ ] 다른 앱에 갔다 돌아왔을 때 보던 화면이 유지된다.

## 7. 알림

푸시는 HTTPS 배포본 + 홈 화면 설치본에서만 동작한다. 로컬이나 Safari 탭에서는 확인할 수 없다.
닉네임은 기기마다 따로 저장되므로 A·B 폰을 나눠 적는다.

준비

- [ ] Vercel에 VAPID 환경변수 3개를 등록한 **이후에** 배포한 빌드다. 공개키는 빌드 시점에 번들로 들어간다.

켜기 (두 기기 각각)

- [ ] 설정 화면에 `알림` 항목과 스위치가 보인다. (실패: "이 브라우저에서는 알림을 받을 수 없어요" — 설치본이 아니거나 공개키 누락)
- [ ] 스위치를 켜면 권한 팝업이 뜬다.
- [ ] 허용하면 스위치가 켜진 채로 남고 아래에 `닉네임` 입력이 나타난다.
- [ ] 닉네임 기본값이 가입할 때 쓴 이름이다. 그 이름이 없으면 `기록자`.
- [ ] 앱을 껐다 켜도 스위치와 닉네임이 그대로다.

닉네임

- [ ] 두 번째 기기에서 스위치를 켜면 "닉네임을 바꿔 주세요" 경고가 뜬다. 기본값이 두 기기 모두 계정 이름이라 겹친다.
- [ ] 닉네임을 바꾸고 `저장`을 누르면 "닉네임을 바꿨어요"가 뜬다.
- [ ] 다른 기기가 쓰는 닉네임으로 바꾸면 다시 경고가 뜬다.
- [ ] 앱을 껐다 켜도 바뀐 닉네임이 남아 있다.
- [ ] **A폰과 B폰에 서로 다른 닉네임을 넣을 수 있다.** 한쪽을 바꿔도 다른 쪽은 그대로다. (실패: 계정 단위로 저장되고 있음)

받기

- [ ] A폰에서 기록을 저장하면 B폰에 알림이 온다.
- [ ] **A폰에는 알림이 오지 않는다.** (실패: `senderEndpoint`가 전달되지 않음)
- [ ] 알림 제목에 A폰의 닉네임이 나온다. `○○님이 기록을 남겼어요`
- [ ] 알림 본문이 그 기록의 활동 내용이다.
- [ ] 반대 방향(B에서 작성)에는 B폰의 닉네임이 나온다.
- [ ] 기록을 수정하거나 삭제할 때는 알림이 오지 않는다. 생성만 알린다.

탭

- [ ] 알림을 탭하면 방금 만든 기록의 상세 화면이 열린다.
- [ ] 앱이 이미 떠 있을 때 탭해도 그 기록으로 이동한다. (실패: 보던 화면 그대로 — `WindowClient.navigate` 미지원)
- [ ] 앱이 완전히 종료된 상태에서 탭해도 열린다.

끄기

- [ ] 스위치를 끄면 닉네임 입력이 사라진다.
- [ ] 끈 뒤에는 상대가 기록을 남겨도 알림이 오지 않는다.
- [ ] 다시 켜면 닉네임을 새로 넣을 수 있다.

권한 거절

- [ ] 팝업에서 거절하면 "알림 권한이 꺼져 있어요" 토스트가 뜨고 스위치가 꺼진 상태로 돌아온다.
- [ ] 거절 후에는 앱 안에서 다시 켤 수 없다. iOS 설정의 알림 목록에서 허용하거나 앱을 지웠다 다시 설치해야 한다. 정상 동작이다.

## 8. 회전 (선택)

매니페스트에 세로 고정을 넣었지만 iOS는 이를 무시할 수 있다.

- [ ] 가로로 돌렸을 때 노치 쪽 콘텐츠가 잘리지 않는다. (잘리면 좌우 인셋 대응을 추가한다)
