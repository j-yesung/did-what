# 기록 지도(journey)

- 경로: `/journey`. 집에서 기록의 지역, 그리고 사용자가 고른 장소 순서대로 자동차 추천 경로를 그려 추억을 따라간다.
- 화면 동작은 코드(`src/pages/journey`)가 기준이다. 이 문서에는 코드만 봐서는 알 수 없는 결정과 남은 일을 둔다.

## 결정과 제약

- 선과 거리·시간은 조회 시점의 자동차 추천 경로이고, 장소를 잇는 순서는 사용자가 배지를 누른 순서다. 실제 이동 경로·소요 시간·방문 순서로 표시하지 않으며 선택 순서를 저장하지 않는다.
- 집 주소(`member_home_addresses`)는 계정과 현재 구성원 조합마다 하나다. 같은 계정의 구성원은 계정 권한을 공유하므로 서로의 주소를 완전히 분리하는 보안 경계는 아니다. 주소 문자열만 저장하고 좌표는 저장하지 않으며, 주소 확인과 집 출발 구간 조회 때마다 카카오 주소 검색으로 변환한다.
- 길찾기 서버는 기록 소유자와 지역·장소 연결을 확인한 뒤에만 조회한다. 브라우저가 보낸 임의 좌표로 길찾기하지 않고, 집 좌표와 REST API 키는 브라우저에 보내지 않는다.
- 배지를 누르면 바로 그려지도록, 기록을 열 때 지역 → 장소와 장소 ↔ 장소 경로를 미리 조회하고(앞의 6곳, 최대 37건) 화면에 있는 동안 TanStack Query에 캐싱한다. 화면을 나가면 지운다. 카카오 데브톡에 "실시간이 아닌 임시 캐싱 등의 방법으로 API 호출 및 이용은 금지"라는 답변(공식 여부·근거 조항 미확인)이 있어, 이 방식은 사용자 판단으로 적용했다. 운영 전에 카카오에 확인한다.
- 자동차 길찾기 무료 제공량은 하루 10,000건이다(2026-10-28 요금 페이지 기준). 장소 4곳짜리 기록은 열 때 약 17건을 쓴다. 다중 목적지 길찾기는 거리·시간 요약만 주고 도로 좌표가 없어 선을 그릴 수 없다.
- 경로를 불러오는 중이라는 표시는 앱 토스트로 띄우지 않는다. 앱 토스트는 결과 알림용(자동으로 사라지고 로딩·직접 닫기가 없음)이고, 재시도·건너뛰기처럼 동작이 필요한 실패는 화면 안에 두는 것이 앱 규칙이다.

## 확인할 것

- 로컬에 Docker/Podman이 없어 로컬 Supabase에서 마이그레이션과 RLS 실행 검증을 하지 못했다. 실제 사용자 세션 사이의 접근 차단은 따로 통합 검증한다.
- 실제 계정과 기기에서 주소 등록, 지역별 기록 목록, 경로 재생, 터치 제스처를 확인한다.
- 기록을 열 때 동시에 나가는 최대 37건이 카카오 초당 호출 제한에 걸리는지 확인한다. 실패한 구간은 배지를 누를 때 다시 받아 흐름은 이어지지만 그때는 기다려야 한다.
- 제주·울릉도처럼 차로 갈 수 없는 곳에서 카카오가 집 출발 경로(배편 포함)를 주는지 확인한다.

## UX 개선 백로그

코드 기준으로 찾은 개선점이며 실제 기기에서 확인한 결과는 아니다. 구현을 마친 항목은 삭제하고 이력은 Git에서 확인한다.

### 흐름

- 지금 보는 기록이 화면에 없다. 기록을 열면 제목은 "대구의 기억"뿐이고, 고른 기록의 이름과 날짜는 기록 읽기를 눌러야 보인다. 제목은 그대로 두고 아래에 "기록 이름 · 날짜"를 작게 표시한다.
- 가까운 지역 점을 누르면 다른 지역이 열릴 수 있다. 점은 반지름 15px 안을 누르면 열려 대전·세종, 대구·경북, 광주·전남, 부산·울산처럼 가까운 점은 범위가 겹친다. 점 위치는 가장 최근 기록의 지역 좌표라 기록을 추가하면 옮겨 간다. 지금은 서울·경기·인천만 고정 목록으로 고르게 한다. 누른 자리 근처에 점이 둘 이상이면 그 지역들을 고르는 시트를 띄우도록 일반화하고 고정 목록을 없앤다.
- 기록을 수정하고 돌아오면 그린 여정이 사라진다. 기록 읽기 → 수정 → 완료 후 돌아오면 전국 지도부터 다시 시작한다. 홈 지도처럼 고른 지역과 기록을 URL에 남겨 이어서 본다.
- 집 → 지역 구간이 실패하면 다시 시도만 있고 건너뛰기가 없다. 차로 갈 수 없는 지역이면 그 기록은 장소 선도 볼 수 없다. 집 구간을 건너뛰고 지역에서부터 장소 선을 그릴 수 있게 한다.

### 다듬기

- 터치 영역: 지역 목록·기록 읽기 버튼은 약 38px, 장소 배지는 약 40px, 지역 점은 지름 30px이다. 44px 이상으로 넓힌다.
- 스타일 통일: 뒤로가기와 "…"는 리퀴드 글래스인데 지역 목록·기록 읽기는 따로 만든 어두운 버튼이다. 지역 목록 시트의 행은 글자 화살표(→)인데 이어서 올라오는 기록 목록(홈 컴포넌트)은 아이콘 화살표다.
- 지역을 누르면 지도가 그 지역으로 확대되지만 전체 높이 기록 시트에 가려 보이지 않는다. 확대를 빼거나 시트를 중간 높이로 열어 지역이 보이게 한다.
- 선택한 배지를 다시 누르면 아무 반응이 없어 고장처럼 느껴질 수 있다. 그 장소로 지도를 옮기고 점을 강조한다. 한 번 고르면 되돌릴 수 없는데 `aria-pressed`(눌렀다 뗄 수 있는 버튼)로 알리고 있어 의미도 맞지 않는다.
- 화면 진입 애니메이션이 없다. 다른 상세 화면처럼 `screen-content-enter`를 적용하고, 뒤로가기로 돌아올 때는 끈다(`PageShell`과 같은 기준).
- 장소 배지 줄은 스크롤바를 숨겨 더 있는지 알 수 없다. 오른쪽 끝을 흐리게 처리한다.
- 지역 점에 이름이 없어 어느 지역인지 알기 어렵다. 구 경계선처럼 확대했을 때만 이름이 서서히 나타나게 한다.
- 방문 지역이 없을 때 안내 문구만 있다. 홈 기록 목록처럼 기록 남기기 버튼을 둔다.
