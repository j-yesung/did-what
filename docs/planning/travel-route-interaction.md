# 기록 지도에서 장소를 이어 보는 흐름

- 상태: 합의한 프로토타입 구현 계획. 아래의 누적 경로 동작은 아직 구현되지 않았다.
- 목적: 기록에 연결된 장소를 사용자가 직접 선택하며 한 번의 기억을 지도에서 따라간다.
- 적용 대상: 기록별 지도 프로토타입. 기존 서비스의 지도 교체나 기록 데이터 변경은 이 문서의 범위가 아니다.

## 출발과 장소 선택

1. 전국 지도에서 방문 지역을 선택하고, 지역 목록에서 기록을 연다.
2. 목록 시트가 닫히면 나의 집에서 기록의 방문 지역까지 자동차 추천 경로를 흰색 선으로 그린다. 집에서 지역까지의 거리와 예상 시간을 표시한다.
3. 방문 장소는 지도 위 거리 정보 위쪽의 배지로 표시한다. 모바일에서는 가로로 밀고, 웹에서는 마우스로 끌어 볼 수 있다.
4. 사용자가 장소 배지를 누르면 마지막으로 도착한 지점에서 선택한 장소까지 새 흰색 선을 그린다. 앞서 그린 선은 유지한다.
5. 예를 들어 대구에 도착한 뒤 A, B를 누르면 `대구 → A → B`가 된다. B에 도착한 뒤 A를 다시 누르면 `B → A`를 추가한다.
6. 현재 도착한 장소를 다시 누르면 새 구간은 만들지 않는다. 이전에 방문한 다른 장소를 다시 누르는 경우에는 그 장소로 돌아가는 구간을 추가한다.

선은 **사용자가 배지를 누른 순서**를 나타낸다. 기존 기록에는 실제 방문 순서가 보장되어 있지 않으므로, 선택 순서나 자동차 추천 경로를 실제 방문 순서·실제 이동 경로로 표시하지 않는다. 새 기록이나 DB에 선택 순서를 저장하지도 않는다.

## 지도와 화면 표시

- 새 구간의 출발점과 도착점이 잘 보이도록 지도를 부드럽게 이동·확대한다. 예전 선이 화면 밖에 있어도 삭제하지 않는다.
- 마지막 도착 지점은 초록색 점과 파동으로 표시하고, 이전에 도착한 지역과 장소는 파동 없는 흰색 점으로 표시한다.
- **전체 경로 보기**를 누르면 지금까지 그린 전체 경로가 보이도록 지도를 축소한다. 지도를 직접 움직이거나 확대·축소할 수도 있다.
- 사용자가 지도를 조작해도 진행 중인 선 그리기는 계속된다. 새 구간의 경로를 조회하거나 재생하는 동안 선택한 기록과 기존 선을 유지한다.
- 거리와 시간은 `집 → 지역 → 선택한 장소들`의 성공한 구간을 누적한다. 시간은 조회 시점의 자동차 예상 시간을 합한 값이며 당시 실제 소요 시간이 아니다. 실패하거나 건너뛴 구간은 합산하지 않는다.
- 기록에 설명이 있으면 **기록 읽기**를 제공한다. 모바일과 웹 모두 확장형 바텀 시트에서 기존 설명을 읽고, 닫으면 선택한 장소와 지도 위치를 유지한다.

## 빠른 선택과 실패 처리

- 지역 도착 전에 장소를 누르더라도 입력을 받아 두고, 집에서 지역으로 이동한 뒤 순서대로 처리한다.
- 경로 조회나 선 그리기 중 여러 배지를 빠르게 누르면 선택 순서대로 대기시킨다. 대기 중인 배지는 진행 상태를 표시한다.
- 각 구간은 마지막으로 **도착한** 지점에서 다음 선택 장소까지 조회한다. 위치와 경로가 준비되지 않은 상태에서 다음 구간을 임의로 이어 그리지 않는다.
- 구간 조회가 실패하면 앞서 성공한 선과 현재 도착 위치를 유지하고 대기열을 멈춘다. 실패한 장소에 대해 **재시도** 또는 **건너뛰기**를 제공한다.
- 예를 들어 `A → B`가 실패한 뒤 B를 건너뛰면, 다음에 대기 중인 C는 A에서 출발해 `A → C`로 조회한다. B에 도착한 것으로 표시하지 않는다.
- 다른 기록을 열거나 전국 지도로 돌아가면 이전 작업을 중단하고, 늦게 도착한 응답이 새 화면을 변경하지 않도록 한다.

## 다시 보기와 유지 범위

- **다시 보기**는 `집 → 지역`부터 시작해 현재 화면에서 사용자가 선택해 성공적으로 이은 장소들을 같은 순서로 재생한다. 건너뛴 장소는 재생 경로에 포함하지 않는다.
- 선택한 장소 순서와 누적 경로는 현재 기록을 보는 동안만 유지한다. 다른 기록을 열거나 페이지를 나가면 초기화한다.
- 장소 선택 이력을 기록에 영구 저장하거나 실제 방문 이력으로 바꾸지 않는다.
- 재생 중 길찾기 결과를 재사용할지 다시 조회할지는 카카오모빌리티의 이용 조건을 확인한 뒤 결정한다. API 결과의 사전 조회·일시 보관·재사용에 대한 허용 범위는 아직 확정되지 않았다.

## 현재 프로토타입과 별도 검토 사항

- 현재 프로토타입의 ‘나의 집’은 임의 좌표다. 실제 사용자의 저장 주소를 쓰는 기능은 별도 설계가 필요하다.
- 현재 지역에서 장소 배지를 누르면 해당 지역에서 선택한 장소까지 한 구간을 표시한다. 이 문서의 이전 선 유지, 구간 대기열, 전체 경로 재생은 앞으로 구현할 동작이다.
- 별도 데모 탭에서는 지역 기록을 처음 15개 표시하고 **더 보기**로 다음 15개를 불러오는 방안을 논의했다. 보이는 항목의 길찾기 사전 조회와 TanStack Query 재사용은 카카오 이용 조건 확인 후 결정한다.
- 자동차 경로 조회에 출발지와 목적지 좌표가 전달된다. 실제 사용자 주소를 연결할 때는 조회 범위와 사용자별 접근을 함께 설계한다.
