# 기록 지도 프로토타입 현황

- 조사일: 2026-10-28
- 범위: 독립 경로 `/prototypes/travel`에서 현재 동작하는 프로토타입. 실제 홈(`/`)과 공개 체험(`/demo`)은 이 화면을 사용하지 않는다.
- 목적: 구현된 상태를 기록하고, [장소를 이어 보는 구현 계획](travel-route-interaction.md)과 구분한다.

## 화면과 동작

- 모바일 크기를 중심으로 대한민국 전국 지도를 화면에 표시한다. 어두운 바탕, 흰색 행정 경계, 방문 지역의 초록색 노드를 사용한다. 확대 정도에 따라 세부 지역 경계가 나타난다.
- 방문한 지역을 누르면 기록 목록 시트가 열린다. 서울·경기·인천이 겹치는 경우 지역을 선택하는 단계를 제공한다. 전국 지역 목록으로도 선택할 수 있다.
- 기록을 누르면 시트가 닫히고, 지도 확대와 함께 ‘나의 집’에서 기록의 방문 지역까지 자동차 추천 경로를 흰 선으로 그린다. 집은 현재 임의 좌표 하나다.
- 선이 도착하면 방문 지역에 초록색 점과 파동이 나타난다. 지도 위 하단에는 선택 기록의 방문 장소 배지와 집에서 지역까지의 거리·자동차 예상 시간이 표시된다. 숫자는 올라가는 효과가 있다.
- 장소 배지를 선택하면 원래 지역에서 선택한 장소까지 다른 자동차 경로를 그린다. 원래 지역은 흰 점이 되고 선택한 장소에 초록색 점과 파동이 생긴다. **다른 배지를 누르면 이전 장소 구간은 교체**된다.
- 장소 배지는 모바일 터치와 웹 마우스 드래그로 가로 이동한다. 장소가 없으면 빈 상태를 표시한다.
- 설명이 있는 기록은 ‘기록 읽기’로 날짜·제목·메모를 확장형 바텀 시트에서 볼 수 있다. 닫아도 지도와 선택 상태를 유지한다. 상단에 지역·날짜 배지는 따로 표시하지 않는다.
- 다시 보기와 전국 지도로 돌아가기를 제공한다. 지도는 드래그·휠·터치 확대/축소를 지원하며, 모션 줄이기 설정을 반영한다.
- 지도 및 경로 정보 버튼에 데이터 출처와 임의 출발지 설명이 있다.

## 데이터와 호출

- `/prototypes/travel`은 로그인 세션을 확인하고 현재 사용자가 소유한 실제 기록을 읽는다. 기록·지역·장소·메모를 500개 단위로 끝까지 조회해 서버에서 지역별로 묶은 뒤 HTML에 전달한다. 지역 시트의 15개 단위 더 보기나 길찾기 사전 조회는 아직 없다.
- 전국 노드는 시·도별로 묶는다. 한 기록에 같은 시·도의 지역이 여러 개면 지역 이름·코드 순으로 정렬한 첫 지역의 저장 좌표를 목적지로 사용한다. 장소는 연결 생성 시각과 장소 ID를 기준으로 표시하며, 이는 실제 방문 순서를 보장하지 않는다.
- `/prototypes/travel/directions`는 세션과 기록 소유자를 확인한다. 집 → 지역 또는 기록에 연결된 장소로의 조회만 허용하고, 임의 좌표를 요청으로 받지 않는다.
- 길찾기는 서버에서 `KAKAO_REST_API_KEY`를 사용해 카카오 자동차 길찾기를 호출한다. 키는 브라우저에 전달하지 않는다. 반환된 도로 좌표로 선을 그리며 거리와 시간은 해당 요청 시점의 추천 경로 값이다. 응답은 `private, no-store`로 제공한다.
- 기록을 누르면 즉시 확대를 시작하고 경로 응답이 도착한 뒤 선을 그린다. 장소를 누르면 해당 구간을 새로 조회한다. 조회 실패 시 재시도를 제공한다.
- `geoBoundaries`와 `citypopulation.de`의 경계 데이터 출처를 화면 정보에 표시한다.

## 구현 파일

- `app/prototypes/travel/route.ts`: 독립된 HTML 프로토타입 진입점.
- `app/prototypes/travel/directions/route.ts`: 길찾기 요청 진입점.
- `src/app/route-handlers/travel-prototype.ts`: 인증·기록 조회와 HTML 응답.
- `src/app/route-handlers/travel-prototype-model.ts`: 지역별 그룹과 기록·장소 데이터 구성.
- `src/app/route-handlers/travel-prototype-directions.ts`: 소유자 검증과 카카오 길찾기 호출.
- `src/app/route-handlers/travel-directions-model.ts`: 임의 출발지와 길찾기 응답 검증.
- `demo/travel-live.html`: 지도, 애니메이션, 시트, 장소 배지와 화면 상호작용. React 화면이나 기존 TanStack Query 제공자에 연결된 화면은 아니다.
- `demo/travel-prototype.html`: 앞서 만든 샘플 중심의 별도 시안.
- 관련 테스트: `travel-prototype-model.test.mjs`, `travel-directions-model.test.mjs`.

## 아직 구현되지 않은 사항과 제한

- 장소를 누른 순서대로 이전 선을 보존해 `지역 → A → B`로 이어 그리는 대기열, 구간 실패 후 재시도·건너뛰기, 누적 거리·시간, 전체 경로 보기와 전체 재생은 [별도 계획](travel-route-interaction.md)이다.
- ‘나의 집’은 사용자의 저장 주소가 아니며, 현재 프로토타입은 선택한 지역의 저장 좌표를 사용한다. 표시된 선·거리·시간은 실제 이동 이력이나 실제 소요 시간이 아니다.
- 카카오 결과를 미리 조회해 일시적으로 보관·재사용하는 방식의 허용 범위는 확인되지 않았다. 실제 출발지 정보 저장 및 접근 방식도 아직 설계되지 않았다.
- 예시 응답을 사용한 모바일 브라우저 검증과 모델 테스트·타입 검사·빌드는 수행했다. 로그인된 실제 계정의 전체 화면 흐름과 실기기 터치는 자동 검증에서 확인하지 못했다.
