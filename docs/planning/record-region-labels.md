# 방문 지역의 표시명과 집계 기준

- 같은 기록에서 지역 코드가 같아도 표시명이 다르면 각각 추가·저장한다.
- 같은 지역 코드와 앞뒤 공백을 제거한 표시명이 모두 같을 때만 중복으로 처리한다.
- 예: `난지 한강공원`, `디지털미디어시티`는 모두 서울 마포구여도 각각 남긴다.
- 지도 점과 방문 지역 집계는 지역 코드로 중복을 제거한다.
- 직접 고른 표시명이 있으면 장소에서 따라오는 같은 지역의 기본 이름은 추가하지 않는다.
- 항목 하나를 삭제해도 같은 지역의 다른 항목이 남아 있으면 방문 장소를 유지한다. 마지막 항목을 삭제할 때는 기존처럼 확인 후 해당 지역의 장소도 제거한다.
- 기존 상한인 방문 지역 항목 10개, 방문 장소 10개를 유지한다. 같은 지역의 서로 다른 표시명도 각각 한 항목이다.
- DB 마이그레이션 `allow_record_region_labels`를 먼저 적용한 뒤 앱을 배포한다. 기존 데이터는 그대로 보존한다.
