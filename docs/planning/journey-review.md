# 기록 지도 남은 확인

## 운영 전 확인

- 경로 캐싱: 받은 경로를 새로고침 전까지 메모리에 캐싱해 다시 보기와 수정 후 돌아왔을 때 재사용한다. 카카오 데브톡에 "실시간이 아닌 임시 캐싱 등의 방법으로 API 호출 및 이용은 금지"라는 답변(공식 여부·근거 조항 미확인)이 있어, 운영 전에 카카오에 허용 여부를 확인한다. 허용되지 않으면 다시 보기 때도 새로 조회하도록 바꾼다.

## 공용 패턴

- URL 갱신이 Next 라우터를 우회한다: `history.replaceState(window.history.state, …)`로 주소를 바꾸면 Next가 바뀐 주소를 몰라, 재검증 서버 액션 뒤 옛 주소로 push해 히스토리가 하나 더 쌓인다. 기록 지도는 `replaceState(null, "", url)`로 고쳤고, 홈 지도(`src/widgets/region-activity-map/ui/region-activity-map.tsx`)·달력·필터에 같은 패턴이 남아 있다. 화면마다 동작을 확인하고 고친다.
